Add camera

Turn on RTSP first in the Reolink app: Settings → Network → Advanced → Port Settings. Find the IP address in the app under Device Info or in your router's device list. To add a built-in test camera, enter a test://… address here; no username or password is needed.
The grid uses a lower-bandwidth view where available; the full view loads the original. The built-in feeds use test://demo, test://reolink-sample, test://reolink-night-day, test://drive-thru, test://city-street and test://night-crossing.
